En este proyecto usaremos MVC porque es más ordenado y, por ende, más fácil de leer a futuro. Esto también le da una ventaja al trabajar en grupo, ya que permitirá que los dos entendamos mejor que hizo cada uno

## Cómo ejecutar

1. Abrir la solución en Visual Studio.
2. Crear la base de datos con `Add-Migration Inicial` y luego `Update-Database`.
3. Ejecutar el proyecto.

Al iniciar, el sistema crea los roles **Administrador** y **Suscriptor** y un usuario administrador de prueba:

- Correo: `admin@portal.com`
- Contraseña: `Admin123!`
